JumpNDodge-Server
=================

Mit diesem Programm hostest du einen eigenen Server für Online-VS und Online-Koop
(je 2 Spieler pro Raum). Die Spieler verbinden sich im Spiel über
Online -> Multiplayer -> "Per IP verbinden".

Starten
-------
Windows:      JumpNDodge-Server.exe doppelklicken
Linux/macOS:  ./JumpNDodge-Server

Beim ersten Start wird server.json neben dem Programm angelegt:

  name       Name in der Serverliste
  motd       Begrüßungstext
  port       UDP-Port (Standard 47800)
  ws_port    TCP-Port für WebSocket (Standard 47801, 0 = aus) - für Cloudflare Tunnel
  bind       "0.0.0.0" = alle Netzwerke (IPv4), "::" = IPv6
  password   leer = jeder darf rein
  max_rooms  maximale Anzahl Räume (je 2 Spieler)
  log_file   Log-Datei (leer = nur Konsole)
  auto_update           true = neue Versionen selbst laden (Standard)
  update_check_minutes  wie oft nachgesehen wird (Minuten, mindestens 5)

Nach einer Änderung den Server neu starten.
Andere Datei oder anderer Port:  JumpNDodge-Server --config pfad/server.json --port 47810

Spieler aus dem Internet
------------------------
1. Im Router eine Portweiterleitung anlegen: UDP-Port 47800 -> dieser PC.
2. Ggf. in der Firewall eingehendes UDP auf Port 47800 erlauben
   (Windows fragt beim ersten Start meistens selbst nach).
3. Deine öffentliche IP-Adresse an die Mitspieler weitergeben
   (z.B. auf https://ifconfig.me nachsehen). Port 47800 muss nicht mit
   angegeben werden, andere Ports als "IP:Port".

Hinweis: Wer sich mit deinem Server verbindet, kennt deine öffentliche IP-Adresse.

Versionen: Spiel und Server müssen nur dasselbe Netzwerk-Protokoll haben. Ältere oder neuere
Spiele mit gleichem Protokoll können mitspielen; bei anderem Protokoll sagt das Spiel, wer
aktualisieren muss.

Ohne Portweiterleitung: Cloudflare Tunnel (WebSocket)
-----------------------------------------------------
Neben UDP hört der Server auf TCP-Port 47801 auf WebSocket-Verbindungen. Damit lässt er
sich hinter einem Cloudflare Tunnel betreiben - ohne Portfreigabe im Router:
1. Cloudflare Zero Trust -> Networks -> Tunnels -> Tunnel anlegen, cloudflared starten.
2. Public Hostname anlegen, z.B. spiel.deine-domain.de -> Service HTTP -> localhost:47801
   (im Docker-Netz: http://<containername>:47801).
3. Mitspieler tragen nur den Hostnamen ein (ohne Port). Cloudflare leitet kein UDP weiter;
   das Spiel merkt das und verbindet sich automatisch über wss://<hostname>.
Fertige Vorlage für CasaOS (Server + cloudflared): Ordner casaos-offiziell im Quellcode.

Auto-Update
-----------
Der Server schaut regelmäßig ins neueste Release, lädt die passende Datei, prüft sie gegen
SHA256SUMS.txt und startet neu, sobald niemand verbunden ist. Abschalten: in server.json
"auto_update": false oder Umgebungsvariable JND_SERVER_AUTO_UPDATE=0.
Im Docker-Container landet die neue Datei in /data/bin; das Startskript nimmt beim Neustart
die neuere von beiden (Image oder /data/bin). Startet die geladene Datei nicht, läuft die
Version aus dem Image weiter.

Docker / CasaOS
---------------
Fertiges Image: ghcr.io/erqf1/jumpndodge-server:latest (amd64 und arm64)

  docker run -d --name jumpndodge-server --restart unless-stopped \
    -p 47800:47800/udp -p 47801:47801/tcp -v jnd-data:/data \
    -e JND_SERVER_NAME="Mein Server" ghcr.io/erqf1/jumpndodge-server:latest

CasaOS: App-Store -> "+" -> Benutzerdefinierte App -> Importieren -> Inhalt von
docker-compose.yml einfügen. server.json liegt dann in /DATA/AppData/jumpndodge-server.
Umgebungsvariablen (überschreiben server.json): JND_SERVER_NAME, JND_SERVER_MOTD,
JND_SERVER_PASSWORD, JND_SERVER_PORT, JND_SERVER_MAX_ROOMS, JND_SERVER_WS_PORT,
JND_SERVER_AUTO_UPDATE.
